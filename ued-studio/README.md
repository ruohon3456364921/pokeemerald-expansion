# UED Studio

pokeemerald-expansion 的本地可视化编辑器。以原来的「反编译小工具」（UniversalEditor）为蓝本重做，
保留它可用的原生读写核心，重写了上层，并把它的两个致命缺陷从设计上规避掉。

## 为什么重做

原工具在保存上有两个叠加缺陷：

1. **App 层**：每次保存都会无条件重写 `.evolutions` 字段，把 `#if` / `#endif` 行丢掉，
   文件字节数因此改变。
2. **原生层**：保存时不更新同文件里其它物种的偏移缓存。下一次保存排在其后的物种时，
   块定位错位 → 块首字段在块内「找不到」→ 被追加到块尾。

结果就是你看到的：**同一条目里出现重复词条**；严重时相邻条目还会被写入别人的数值。

原工具是闭源二进制，原生层无法修。本工具的做法是**绕开**而不是硬修：

- 每次保存都新开一个项目会话，保存完立刻关闭 —— 拿到全新偏移；
- 只提交你真正改过的字段，其余字段一个字节都不碰；
- 保存前后做逐块校验，任何异常自动回滚；
- 每次成功保存留快照，可一键撤销。

## 启动

需要 Windows 上的 Python 3.9+（原生库是 Windows x64 DLL）。

### 方式一：装到本机（推荐）

双击 `install.bat`。它会把工具复制到 `%LOCALAPPDATA%\UEDStudio` 并记住项目路径。
以后直接双击那里的 `run.bat`，不会再弹安全警告。

### 方式二：就地运行

双击本目录的 `run.bat`。

第一次会弹 Windows 安全警告——因为文件在 WSL 里，Windows 把它当作「网络位置」，
这是正常的，点 **运行(R)** 即可。若不想再看这个提示，用方式一。

### 方式三：命令行

```bat
python app.py /mnt/d/path/to/pokeemerald-expansion
```

不传参数时会用上次记住的项目路径，再退回到本目录的上一级。
启动后自动打开浏览器；不想要就设 `UED_NO_BROWSER=1`。

### 启动失败怎么办

`run.bat` 出错时会停住并显示原因。若窗口仍一闪而过，用 PowerShell 跑一条看报错：

```powershell
python "\/home/ruo/pokeemerald-expansion/ued-studio/app.py"
```

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示找不到 `app.py` | 从 UNC 路径运行，`cd` 失败 | 用 `install.bat` 装到本机 |
| `'python' 不是内部或外部命令` | 没装 Python 或没进 PATH | 重装并勾选 Add Python to PATH |
| `端口被占用` | 8765 已被占用 | `set UED_PORT=8899` 后再运行 |

## 界面

- 左侧：物种列表，支持按中文名 / 符号 / 编号搜索；
- 右侧：按「战斗 / 培育 / 图鉴 / 图形 / 形态与进化 / 招式」分组的字段；
- 改动过的字段会高亮，底部浮条显示改动数量；
- 「体检」扫全工程，报告条目内重复成员和 `species.h` 枚举重复；
- 「撤销上次保存」用快照覆盖回去。


## 界面功能（v2）

### 字段汉化与下拉

- 89 个字段全部有中文名（`field_labels.json`，可自行修改）；
- 属性的下拉选项显示中文（草、毒、火…），三个格子分别是属性 1、属性 2；
- 特性三个格子对应 特性1 / 特性2 / 隐藏特性，选项来自 `src/data/abilities.h` 的中文名；
- 蛋组、成长曲线、身体颜色、性别比例、携带道具、布尔开关（TRUE/FALSE）都是下拉；
- 遇到无法解析的表达式（比如带宏的条件写法）会自动退回普通文本框，不会误改。

### 招式编辑

「招式」标签页分三块，对应三个不同的数据源：

| 类型 | 编辑的是 | 说明 |
| --- | --- | --- |
| 升级招式 | `src/data/pokemon/level_up_learnsets/gen_*.h` | 每行「等级 + 招式」，保存时按等级稳定排序 |
| 蛋招式 | `src/data/pokemon/egg_moves.h` | 只存在于家族基础形态；进化型显示"继承基础形态" |
| 教学招式 | `src/data/pokemon/all_learnables.json` | 这是 `teachable_learnsets.h` 的源数据 |

注意：改完教学招式后，`teachable_learnsets.h` 需要重新生成（`make` 时会自动做），
因为这个头文件开头写着 *DO NOT MODIFY THIS FILE*。

招式名支持按中文或英文搜索，选中后内部存 `MOVE_XXX` 符号。

### 招式保存同样走安全流程

快照范围现在包含 10 个物种文件、`species.h`、9 个 learnset 文件、`egg_moves.h`、`all_learnables.json`。
校验会确认：除目标块外，其它内容逐字未变；`all_learnables.json` 其它物种的值未变。

## 安全机制

保存一只宝可梦时依次做：

1. 内存快照 `src/data/pokemon/species_info/*.h` 与 `include/constants/species.h`；
2. 校验字段名必须存在于该物种（禁止凭空新增字段）；
3. 校验取值（整数字段必须仍是整数，禁止换行 / 分号 / 花括号）；
4. 新开会话 → `update_species`（只带改动字段）→ `save` → 关闭会话；
5. 校验：
   - 其它物种块必须逐字不变（抓串味）
   - 目标块不得新增重复成员（抓词条重复）
   - `species.h` 不得被改
   - 改动的字段确实写成了
6. 任何一步失败 → 用快照原子回滚，界面报错；
7. 成功 → 快照存入 `.ued-studio/history/`，保留最近 30 次。

## 与原型的功能差异

| 能力 | 原型 | 本工具 |
| --- | --- | --- |
| 物种编辑 | 有 | 有 |
| 道具 / 训练家编辑 | 有 | 原生层已封装（`ued_core.py`），界面暂未做 |
| 新增物种 | 不支持 | 不支持（原生层不支持） |
| 招式表编辑 | 有 | 暂未做 |
| 保存安全 | 无校验 | 快照 + 校验 + 回滚 + 撤销 |
| 工程体检 | 无 | 有 |

## 目录

```
ued-studio/
  app.py             本地 HTTP 服务 + API + 安全保存流程
  ued_core.py        原生库 ctypes 封装
  safety.py          块解析、快照、校验、体检
  field_groups.json  字段 -> 分组映射
  lib/               原生库
  web/               前端（原生 JS，无构建步骤）
```

## 已知限制

- 原生库闭源，只能规避不能修；每次保存会重开项目，单次保存约 0.3–0.8 秒。
- `description` 这类多行字段只读展示，请在源码里改（避免被重排）。
- 一次只改一个物种；批量改多个仍需要逐只保存（这是安全设计的代价）。

## 环境变量

- `UED_PORT`：监听端口，默认 `8765`。端口被占用时换一个即可。

```bat
set UED_PORT=8899
python app.py
```

在工程副本上用原生接口实测：

| 场景 | 结果 |
| --- | --- |
| 连续保存皮卡丘、雷丘、波波（原型会重复的那组） | 三个文件各只改 1 行，体检 0 重复 |

| 提交不存在的字段 | 拒绝，不写盘 |

| 撤销上次保存 | 精确恢复上一次改动前的内容 |
| 全工程体检 | 1364 条目，当前 0 重复 |
